# What is FitLog?
FitLog is a workout planning web app where you can:
-Browse a library of 12+ workouts from an API.
-View detailed instructions, sets, reps & equipment.
-Add workouts to your **Today's Plan** (max 5 per day).
-Save workouts for later.
-Track your daily exercises, minutes & calories.
-Data persists in your browser (localStorage).

# Key Features
**Workout Library** - Browse 12+ workouts with images, tags, and stats.
**Dynamic Details Page** - View instructions, specs, and equipment.
**Today's Plan** - Add up to 5 workouts per day with toast confirmation.
**Saved for Later** - Bookmark workouts to try later.
**Live Metrics** - Real-time calculation of exercises, minutes, and calories.
**LocalStorage Persistence** - Plan and saved data survive page reloads.
**Fully Responsive** - orks perfectly on mobile, tablet, and desktop.
**Toast Notifications** - User-friendly feedback for every action.
**Custom Dark Theme** - Figma-matched design with lime accent.
**Custom 404 Page** - Friendly error page for invalid routes.
